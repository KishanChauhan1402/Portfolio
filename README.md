# Kishan Chauhan — Portfolio

A modern, immersive personal portfolio and digital playground showcasing product design, UI/UX architecture, spatial computing interfaces, and creative development.

## 🚀 Features

- **Immersive UI Design**: Featuring a signature hero section with scroll-zoom interactions.
- **Dynamic Projects Showcase**: Detailed case studies of product design (Elevate LMS), spatial computing (CHRONOS SPATIAL), and hardware UI (MONOLITH SOUND).
- **Experimental Playground**: WebGL, fluid dynamics, and generative audio visualizers.
- **Smooth Animations**: Powered by Framer Motion for kinetic typography and micro-interactions.
- **Custom Follower Cursor**: Interactive and fluid mouse tracking experience.
- **Fully Responsive**: Carefully crafted for all screen sizes using Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open the local URL provided by Vite in your browser to view the portfolio.

## 📁 Project Structure

- `src/components/`: Reusable UI components and page sections (Hero, Projects, Philosophy, Expertise, etc.)
- `src/data/`: Centralized content data (projects, playground items, capabilities, process steps).
- `src/App.tsx`: Main application entry point orchestrating the sections and intersection observers.

## 🎨 Design Philosophy

Focusing on spatial layout, optical balance, density hierarchy, keyboard navigation, micro-interactions, and frictionless user flows. The portfolio itself is a testament to blending Swiss minimalism, editorial storytelling, and silky smooth scroll narratives.
